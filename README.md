# CampusConnect — Aarambh 2.0 Web Development Hackathon (Question 2)

## Folder Structure
Keep these three files in the same folder to run your project locally in any browser:
- `index.html` — Page layout, navigation sidebar, college info strip, sections, and student dashboard
- `style.css` — Responsive styling, color variables, cards, filter chips, and mobile drawer
- `script.js` — Interactive data and logic for events, notices, clubs, faculty, departments, live search/filtering, and profile persistence

## Required Hackathon Features Included
1. **Homepage with College Info & Navigation Menu**: Hero highlight banner, quick college info strip (`#collegeInfo`), Campus Guide modal, and responsive sidebar navigation.
2. **Notices & Important Announcements**: Priority badges (`IMPORTANT`, `UPDATE`, `DEADLINE`) with one-click filter chips.
3. **Upcoming College Events & Activities**: 6 campus events with category filters and instant `Join / Joined ✓` registration saved in `localStorage`.
4. **Clubs, Societies, Faculty & Departments**:
   - 8 interactive student clubs with coordinator details and membership toggle.
   - 8 faculty directory profiles (`#faculty`) with department filter chips, specialization, and office hours modal.
   - 6 clickable academic departments (`#departments`) showing HOD, labs, and intake details.
5. **Student Dashboard / Profile Interface**: View registered events, joined clubs, and edit your student name, department, and semester.
6. **Search & Filter Functionality**: Live search bar (`⌘K` / `Ctrl+K`) + category filter chips for Events, Notices, and Faculty.
