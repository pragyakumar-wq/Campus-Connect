# CampusConnect — Aarambh 2.0 Web Development Hackathon (Question 2)

## Folder Structure
Keep these three files in the same folder to run your project locally in any browser:
- `index.html` — Page layout, navigation sidebar, college info strip, sections, campus blueprint map, helpboard, and student dashboard
- `style.css` — Responsive styling, Light & Dark theme variables, cards, filter chips, and mobile drawer
- `script.js` — Interactive data and logic for events, notices, clubs, faculty, departments, campus map, helpboard, live search/filtering, and `localStorage` persistence

## Complete Aarambh 2.0 Checklist (All 6 Requirements + Bonus Features)
1. **Homepage with College Info & Navigation Menu**: Hero highlight banner, quick college info strip (`#collegeInfo`), Campus Guide modal, Dark Mode toggle (`☾`/`☀`), and responsive sidebar navigation.
2. **Notices & Important Announcements**: Priority badges (`IMPORTANT`, `UPDATE`, `DEADLINE`), filter chips, and live `+ Post notice` form.
3. **Upcoming College Events & Activities**: 6+ campus events with live countdown badges (`In 5 days`), clickable detail modals, `+ Add event` creator form, and `Join / Joined ✓` registration.
4. **Clubs, Societies, Faculty & Departments**:
   - 8 interactive student clubs with coordinator details and membership toggle.
   - 8 faculty directory profiles (`#faculty`) with department filter chips and office hours modal.
   - 6 clickable academic departments (`#departments`) showing HOD, labs, and intake details.
5. **Student Dashboard / Profile Interface**: View registered events, joined clubs, weekday class timetable (`MON`–`FRI`), student service quick links, editable profile, and a shareable **Digital Student Event Pass**.
6. **Search & Filter Functionality**: Live search bar (`⌘K` / `Ctrl+K`) + category filter chips across Events, Notices, Faculty, Campus Map, and Helpboard.
